
##  Jogo Da Velha
jogo simples feito em python, com lógica que atende aos requisitos para jogar o jogo da velha. Com duas funções uma para apresentar a interface(o tabuleiro) e outra para validar a vitoria para os 8 cenários possiveis.

- Sistema feito em try para tratar casos de letras no lugar de número

- Sistemas de função e manipulação de string
